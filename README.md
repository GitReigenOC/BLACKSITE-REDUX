░▒▓ BLACKSITE - REDUX ▓▒░
CLASSIFIED COMBAT SIMULATION // BUILD 1.2.0⚡ 

OVERVIEW: BLACKSITE-Redux is a high-velocity, browser-based 3D FPS built with Three.js and WebGL. Inspired by fast-paced arena shooters like Rivals and Redliner on Roblox, alongside the sleek aesthetic of Call of Duty: Black Ops 3, it features momentum-based physics, explosive rocket jumping, customizable 3-weapon armories, multi-tier tactical maps, and intense AI wave combat.🔥 

KEY FEATURES🚀 Redliner Movement Engine: High-momentum locomotion with air-strafing, ground sliding, sprint transitions, and explosive Rocket Jumping across deep map abysses.

🎮 Multiple Game Modes: Solo Wave Survival: Fight off escalating hostiles with complete ammo reserve refills & combat buffs every 5 waves.Training Grounds: Sandbox environment with target dummies, infinite ammo toggles, and movement parkour courses.1v1 Duel Arena: Ranked 1v1 arena combat with round resets and scoreboards.Multiplayer (P2P/Local): Cross-tab co-op and public/private lobby server browsers.

🎯 Advanced Gunplay & Juice:3-weapon loadouts (e.g., MK-7 Carbine, Shotgun, Rocket Launcher). Aim-down-sights (ADS) smooth zoom transitions. Procedural weapon slanting, sway, bobbing, and inspect animations (F). Dynamic hit markers with headshot audio pings and a dissolving red-skull UI elimination effect.

🛠️ Armory & Shop: In-game economy system to acquire weapon attachments, weapon camos, and character skins.

🖥️ Zero-Filter Modern Visuals: High-contrast, clean sci-fi lighting with volumetric fog, dynamic shadows, and metallic materials—no retro VHS filters.
